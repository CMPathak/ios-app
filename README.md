# The Pet Station - iOS App (SwiftUI)

This project is a standalone iOS App (SwiftUI + WKWebView) for **The Pet Station**.

## Features
- Fullscreen WebView wrapper for `https://www.thepetstation.in/`
- Bottom Navigation Bar with 5 Tabs:
  - 🏠 Home
  - 🛍️ Shop
  - 🔍 Search
  - 🛒 Cart
  - 👤 Account
- Injected CSS to hide website footer automatically.

## How to Build & Run
### Option 1: On Mac using Xcode
1. Open `ThePetStation.xcodeproj` in Xcode.
2. Select your iOS device or Simulator.
3. Click **Run** (Cmd + R).

### Option 2: Automatic Cloud Build via GitHub Actions (.ipa File)
1. Push this folder to a GitHub repository.
2. Go to **Actions** tab on GitHub.
3. Download the generated `ThePetStation.ipa` file artifact!
